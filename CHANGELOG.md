## Versioning Policy

JERTINA follows Semantic Versioning.

Format:

MAJOR.MINOR.PATCH

Example:

1.0.0

- MAJOR = Breaking changes
- MINOR = New functionality
- PATCH = Fixes and improvements

## Release Types

### Alpha

Internal development.

Example:

0.2.0-alpha.1

---

### Beta

Feature complete.

Example:

0.9.0-beta.1

---

### Release Candidate

Production candidate.

Example:

1.0.0-rc.1

### Stable
