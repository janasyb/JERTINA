# Accessibility Standard

## JERTINA

**Version:** v0.1.0  
**Status:** Draft for Review  
**Milestone:** RF-022

---

## Principles

- Use semantic HTML.
- Maintain visible focus states.
- Ensure keyboard navigation works.
- Use accessible contrast ratios.
- Provide meaningful labels for controls.
- Avoid color-only communication.

## Review Checklist

- [ ] Headings are structured correctly
- [ ] Buttons and inputs have accessible labels
- [ ] Focus states are visible
- [ ] Images have meaningful alt text
- [ ] Interactive controls are keyboard accessible
- [ ] Color contrast is reviewed
