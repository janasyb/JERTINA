## Purpose

This milestone establishes the first production-grade CI/CD surface for JERTINA.

## Goals

- Run build, typecheck, test, and smoke validation on every push.
- Prepare a consistent release flow for tagged versions.
- Keep validation inside the repository and visible in GitHub Actions.
- Use the same Node and pnpm versions used locally.
