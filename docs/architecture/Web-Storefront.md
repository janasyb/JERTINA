# Web Storefront Architecture

## JERTINA

**Version:** v0.1.0  
**Status:** Draft for Review  
**Milestone:** RF-008

---

## Objective

Create the customer-facing commerce experience for JERTINA.

---

## Core Areas

- Homepage
- Category browsing
- Product discovery
- Product detail pages
- Cart
- Checkout entry points
- Customer account entry points
- Support and policy pages

---

## Implementation Direction

- Next.js app router
- Shared UI from `packages/ui`
- Shared design tokens from `packages/design-tokens`
- Data from backend services and database layer
- Accessible, fast, mobile-first UX
