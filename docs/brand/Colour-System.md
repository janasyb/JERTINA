## Core Colours

| Token | HEX | Role |
|------|-----|------|
| Primary | #0F2A5F | Brand anchor |
| Secondary | #00A3FF | Interactive accent |
| Success | #19C37D | Positive states |
| Neutral 950 | #0F172A | Strong text / dark UI |
| Neutral 50 | #F8FAFC | Light background |
| White | #FFFFFF | Base background |

---

## Usage Principles

- Use the primary color for brand anchors and key actions.
- Use the secondary color sparingly for emphasis.
- Use neutrals for structure, spacing, and readability.
- Maintain accessible contrast for all text and controls.
