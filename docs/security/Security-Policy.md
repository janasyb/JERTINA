# Security Policy

## JERTINA

**Version:** v0.1.0  
**Status:** Draft for Review  
**Milestone:** RF-021

---

## Policy Statement

JERTINA protects customer, operational, and business data through layered security controls, least privilege, and reviewable deployment practices.

## Rules

- Never commit live secrets.
- Review dependency changes before release.
- Restrict access to production systems.
- Log security-relevant events in secure systems.
- Rotate secrets and credentials on a schedule.
- Use the approved disclosure process for vulnerabilities.

## Ownership

Security concerns are reviewed by the engineering team and escalated to the founder for business-critical impact.

## Enforcement

Violations may result in access removal, release blocking, or incident review.
