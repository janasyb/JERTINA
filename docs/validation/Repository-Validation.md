# Repository Validation

## JERTINA

**Version:** v0.1.0  
**Status:** Draft for Review  
**Milestone:** RF-011

---

## Validation Goals

- Confirm the repository structure is complete.
- Verify core packages and services exist.
- Ensure the project index reflects the current state.
- Provide a repeatable smoke test for new contributions.
- Add CI guardrails for future automation.

---

## Validation Scope

### Structure Checks
- Root files exist
- Workspace folders exist
- Shared packages exist
- Services exist
- Applications exist
- Documentation folders exist

### Content Checks
- Project index is updated
- Required architecture docs exist
- Shared package manifests are present
- Service manifests are present
- App manifests are present

### Quality Checks
- Markdown files render
- Package names follow JERTINA conventions
- Repository metadata remains in sync
